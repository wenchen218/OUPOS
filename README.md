# OUPOS

**為餐飲店打造的 iPad POS 點餐與收銀系統。**

OUPOS 將點餐、菜單管理、配料選擇、結帳、熱感出單與營業報表整合在同一個操作介面，適合早餐店、飲料店、小吃店及其他需要現場點餐的商家。

🌐 **官方網站：[oupos.app](https://oupos.app)**

## 主要功能

| 功能 | 說明 |
| --- | --- |
| 快速點餐 | 依分類選擇商品、調整數量及配料，集中管理購物車。 |
| 菜單管理 | 新增與編輯商品分類、品名、價格、配料及適用商品。 |
| AI 新增菜單 | 將菜單照片或 PDF 交由慣用的 AI 轉成 JSON，再匯入 OUPOS。 |
| 多種配料模式 | 複選可重複加份數、單選同組擇一、勾選可選多項且各限一次。 |
| 結帳與訂單 | 設定付款方式、桌號或取餐位置、備註，建立並查詢訂單。 |
| 熱感出單 | 透過店內區域網路連接支援 TCP／ESC-POS 的出單機。 |
| 營業報表 | 依時間區間查看營業金額、商品銷售及付款方式統計。 |
| 帳號權限 | 區分管理員與員工，讓日常點餐和後台設定分開管理。 |
| 備份與還原 | 使用 JSON 檔案備份或還原菜單、訂單及相關設定。 |

## 開始使用

OUPOS 適用於 **iPadOS 17 或更新版本**。

1. **輸入商家名稱**：首次開啟 App，輸入要顯示在 OUPOS 中的店名。
2. **建立管理員帳號**：設定管理員帳號與密碼。
3. **建立菜單**：進入「設定 → 菜單與配料」，新增商品分類與商品，或使用「AI 新增菜單」匯入。
4. **開始點餐**：返回點餐畫面，選擇商品並進行結帳。

往後可使用管理員或員工帳號登入。登入狀態最長保留 **24 小時**；主動登出後需重新登入。

## 使用教學

### 1. 新增分類與商品

1. 使用**管理員帳號**登入。
2. 進入 **設定 → 菜單與配料**。
3. 在「**分類**」頁籤新增分類，例如「吐司」、「蛋餅」、「飲品」。
4. 切換到「**商品**」頁籤，選擇分類並填寫商品名稱、售價。
5. 點選新增或儲存，即可在點餐畫面選擇該商品。

已建立的商品可以再次編輯。暫時無法販售時，可在「**商品供應狀態**」將商品切換為「售完」；售完商品無法加入購物車，也無法結帳。

### 2. 設定配料與選擇方式

進入 **設定 → 菜單與配料 → 配料群組**，先建立配料群組，再至「**配料**」新增內容、價格、選擇模式與適用商品。

| 模式 | 操作方式 | 使用範例 |
| --- | --- | --- |
| **複選** | 每點一次配料卡片就增加 1 份；已選配料的左上角可按「－」減少。 | 加蛋 ×5 |
| **單選** | 同一群組只能選 1 項，選另一項會取代前一項。配料卡片為**粉紅色**。 | 溫度：去冰／微冰／熱 |
| **勾選** | 同一群組可勾選多項，但每項最多 1 次；再次點選可取消。配料卡片為**黃色**。 | 果醬：草莓＋花生＋巧克力 |

**配料設定小技巧：**

- 需要讓某個分類的全部商品都能加料時，在「配料」的適用商品設定中選擇分類，再使用「**全選此分類**」。
- 「溫度」與「甜度」應分別建立不同的單選群組。
- 配料群組的「最多選取數量」填 **0** 代表不限份數／項數；若要加蛋 5 份，上限應設為 0 或至少 5。

### 3. 使用 AI 新增菜單

不必逐筆輸入大量商品。OUPOS 可以匯入 AI 整理的 JSON 菜單：

1. 在 **設定 → 菜單與配料** 點選「**AI 新增菜單**」。
2. 點「**複製 AI 提示詞**」。
3. 前往 [ChatGPT](https://chatgpt.com/)、[Claude](https://claude.ai/) 或 [Gemini](https://gemini.google.com/)，上傳自己的菜單照片、PDF 或文字，並貼上提示詞。
4. 將 AI 輸出的 JSON 儲存成 `.json` 檔案，或直接複製 JSON 內容。
5. 回到 OUPOS，選擇 JSON 檔案或貼上文字，先**檢查匯入預覽**。
6. 確認分類、商品與配料內容無誤後，按「**確認匯入**」。

匯入會**新增缺少的資料**，不會覆蓋已存在的同名商品或配料。請特別核對 AI 辨識的品名與價格；正式大量匯入前建議先備份。

### 4. 點餐與結帳

1. 在「**點餐**」畫面，從左側選擇商品分類。
2. 點選商品加入購物車；需要加料時，使用商品下方的配料卡片選擇內容。
3. 在購物車確認商品、數量及金額，也可以調整商品數量或移除品項。
4. 進入「**結帳**」，選擇付款方式、桌號／取餐位置（如適用），並輸入訂單備註。
5. 視需要切換「**出單：開啟／關閉**」，確認後按「**下單**」。

訂單編號格式為 **`YYMMDD`＋4 位隨機數字**，例如 `2610244827`。訂單建立後可在歷史訂單中查閱。

> OUPOS 的付款方式是**記錄訂單付款類型**，不是直接串接線上刷卡或電子支付收款服務。

### 5. 設定熱感出單機

1. 確認 iPad 和印表機位於可以互通的店內網路，並在 iPadOS 允許 OUPOS 使用**區域網路**。
2. 使用管理員帳號進入 **設定 → 出單機**。
3. 輸入印表機的 **IP 位址**及 **TCP 連接埠**。
4. 依設備選擇 **58 mm** 或 **80 mm** 熱感紙寬度，儲存設定。
5. 如出現印製順序上下顛倒或文字左右鏡像，可在同一頁切換對應的**列印方向校正**選項。
6. 建立測試訂單並啟用出單，確認店名、品項、配料及金額完整顯示。

出單內容包含店名、內用／外帶、訂單編號、下單時間、付款方式、備註、商品／配料明細與總金額；收據底部印有 OUPOS Logo。是否支援完整排版與裁紙取決於印表機的 ESC/POS 相容性。

### 6. 查看歷史訂單與營業報表

進入「**報表**」查看指定時間區間的營業資料，包括訂單、商品銷售與付款方式統計。可開啟訂單詳情，查看明細並在需要時**重新出單**。

如果要作廢訂單，可在訂單詳情使用「**作廢本機訂單**」。此功能會更新 OUPOS 的訂單狀態與統計，**不會執行實際退款**。

### 7. 建立員工帳號

1. 使用管理員帳號開啟 **設定 → 員工帳號**。
2. 輸入員工帳號、密碼並新增。
3. 員工登入後可**建立訂單**及**切換商品售完狀態**，不能更改商品價格或其他管理設定。
4. 管理員可在同一頁重設員工密碼或刪除員工帳號。

管理員忘記密碼時，可在登入畫面點選「**忘記管理員密碼？**」，依畫面指示使用 Face ID 或 Touch ID 驗證並設定新密碼。

### 8. 備份與還原

進入 **設定 → 備份還原**：

- **匯出 JSON 備份**：將商品、配料、桌號、支付方式、歷史訂單及出單機設定匯出成檔案，建議另外保存到安全的位置。
- **從 JSON 還原**：選擇先前匯出的備份檔，將內容還原到 App。**還原會覆蓋現有本機營業資料**，執行前請先備份目前資料。

建議定期備份，尤其是在更換 iPad 或刪除 App 前。**本機管理員／員工帳號不包含在營業資料 JSON 備份內**，更換設備時需要另外設定帳號。

## 常見問題

**Q：匯入 AI 菜單時出現 JSON 格式錯誤？**  
A：請確認 AI 輸出的是符合 OUPOS 提示詞格式的 JSON，商品分類、價格與配料群組名稱正確。可以先將內容存成 `.json` 檔案再匯入。

**Q：為什麼無法選取某項商品？**  
A：先檢查商品是否被設為「售完」，並確認該商品已啟用及設定正確分類。

**Q：出單機沒有列印？**  
A：請確認印表機電源、紙張、IP、TCP 連接埠、網路互通情況，以及 iPadOS 的 OUPOS 區域網路權限。

**Q：關閉 App 後需要重新登入嗎？**  
A：在登入的 24 小時有效期內，通常可重新開啟繼續使用；主動登出或登入狀態到期後需重新登入。
